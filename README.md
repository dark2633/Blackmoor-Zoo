# Blackmoor Zoo
This is one of the apps I created as part of my Software Development course at college, and is made in C#.

<img width="2367" height="1332" alt="image" src="https://github.com/user-attachments/assets/e02f8c64-f04a-4039-b7e7-595f64b358e5" />

### Description
I created this app for the hypothetical client, Blackmoor Zoo. My task for them was to create an interactive experience, which would allow users to book a visit at the zoo, while also being able to browse information about the facilities.
The app also features a Signup/Login system, with details being stored, as well as storing the booking information upon completion.
